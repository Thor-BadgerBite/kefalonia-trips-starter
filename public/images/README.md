# Images Directory

This directory should contain images for POIs and trips.

## Required Images (for current mock data)

### POI Images:
- `myrtos.jpg` - Myrtos Beach
- `melissani.jpg` - Melissani Cave
- `assos.jpg` - Assos Village
- `fiskardo.jpg` - Fiskardo
- `agiaefimia.jpg` - Agia Efimia

## How to Add Images

### Option 1: Use Real Photos
1. Find or take high-quality photos of Kefalonia landmarks
2. Resize to 1200x800px for optimal web performance
3. Save as JPG with 80% quality
4. Name them according to the list above

### Option 2: Use Placeholder Services (for development)
You can use placeholder services like:
- `https://placehold.co/1200x800/2563eb/ffffff?text=Myrtos+Beach`
- `https://picsum.photos/1200/800`
- `https://via.placeholder.com/1200x800`

### Option 3: Unsplash/Pexels (Free Stock Photos)
Search for Kefalonia landmarks on:
- https://unsplash.com
- https://pexels.com

Make sure to check the license and attribution requirements.
